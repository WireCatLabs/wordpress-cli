# wordpress

`wordpress` is a WireCat command-line tool for the terminal, for scripts and for AI agents.
Its `api` group reaches WordPress, one command per operation of its API description. The sample's `comments`
group shows how a command reaches a service; its made-up address never resolves.

It has the commands every WireCat CLI shares: `doctor`, `commands`, `config`, `skill`, `mcp`, `runs` and `upgrade`,
and the sample's `session` and `comments`.
Start with [installation](installation.md), then [usage](usage.md).
